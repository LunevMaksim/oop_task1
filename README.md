# Журнал успеваемости (Задача №12)

Учебный проект на Java 21 / Maven для автоматизации учёта успеваемости студентов, проведения пересдач и вычисления рейтингов.

## Технологический стек
* **Java 21**
* **Apache Maven**
* **JUnit 6**

## Основной функционал
* **Учёт оценок**: Добавление результатов за контрольные точки с автоматической валидацией допустимых диапазонов баллов.
* **История пересдач**: Поддержка повторных попыток с автоматическим учётом номера попытки и ограничением (максимум 3 попытки на контрольную точку).
* **Аналитика и отчёты**:
    * Вычисление средних баллов студента и группы по дисциплине.
    * Автоматическое формирование списков отличников (баллы >= 85) и должников (баллы < 50).
    * Формирование ведомости по дисциплине на определенную дату.
* **Взвешенный рейтинг**: Расчёт рейтинга студента с учётом индивидуальных весов контрольных точек.

## Запуск проекта и тестов

Запуск демонстрационного сценария:
```bash
mvn compile exec:java -Dexec.mainClass="org.example.Main"

Запуск Unit-тестов:
Bash

mvn test
